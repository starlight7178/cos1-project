# Version Control & Markdown

## What is Version Control?

Version control is a system that tracks changes to files over time.

## Benefits of Version Control

- Tracks project history
- Allows recovery of previous versions
- -Helps organize development work

- ## What is markdown?

- Markdown is a lightweight markup language used to format text.

- ## Markdown Examples

- # Heading 1

- ## Heading 2

- ### Heading 3

- - Bullet Item 1
    - Bullet item 2
   
    - **Bold Text**
   
    - *Italic Text*
